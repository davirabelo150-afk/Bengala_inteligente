# 🦯 Bengala Inteligente

## 📌 Sobre o Projeto

O projeto **Bengala Inteligente** tem como objetivo desenvolver uma solução tecnológica para auxiliar pessoas com deficiência visual na identificação de obstáculos durante sua locomoção.

O sistema utiliza um Arduino em conjunto com um sensor ultrassônico, responsável por identificar objetos próximos. Quando um obstáculo é detectado, um buzzer emite um alerta sonoro para avisar o usuário.

## 🎯 Objetivo

Desenvolver uma bengala inteligente, acessível e funcional, capaz de aumentar a segurança e a autonomia de pessoas com deficiência visual, utilizando componentes eletrônicos de baixo custo.

## ⚙️ Funcionalidades

- Detecção de obstáculos por meio de sensor ultrassônico.
- Identificação de objetos próximos ao usuário.
- Emissão de alertas sonoros através de um buzzer.
- Auxílio na locomoção e prevenção de colisões.
- Funcionamento baseado em Arduino.

## 🔧 Componentes Utilizados

- Arduino Uno;
- Sensor ultrassônico HC-SR04;
- Buzzer;
- Bateria de alimentação;
- Protoboard;
- Fios jumper;
- Estrutura para a bengala.

## 💻 Tecnologias Utilizadas

- **Arduino IDE:** programação e desenvolvimento do sistema.
- **Tinkercad:** criação e simulação do circuito eletrônico.
- **GitHub:** armazenamento e documentação do projeto.

## 🔬 Simulação do Projeto

O circuito foi simulado em sala com um prototipo fisico da bengala inteligente.
